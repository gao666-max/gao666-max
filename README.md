## 我如何工作

在 [horizon 黑客松](https://github.com/gao666-max/opc-opportunity-radar) 里我验证了一套 **「AI 协作型工程师」** 范式：

1. **AI 生成** —— 用 Claude Code 加速执行，24h 交付 15 个接口
2. **人工审查** —— 手写测试验证，抓到 `req.on('close')` 误触发等 3 个关键 bug
3. **降级兜底** —— 没有 API Key 也能演示，不给「跑不起来」留借口
4. **留好 HANDOFF** —— 任何 Agent clone 仓库 3 分钟恢复上下文

> 我的核心策略：用 AI 弥补编码短板，用翻译能力和路演能力放大优势。目标是 **AI 解决方案 / 交付**，不是纯写代码。
